# KaamVaani

Voice-first platform that helps informal workers find nearby work and prove their skills.

**Team PLOT TWIST** | wHACKiest 2026 | Track 4 (UnlockED)
Team ID: d37358c5

## Problem
India's informal workers can't find work close to home or prove their skills, because most job platforms expect English, an app install and a CV.

## Solution
- Voice-first signup, job posting and alerts in Kannada and Hindi
- Hyperlocal matching within 5 km
- VideoProof: 30-second skill demo, AI-scored and peer-endorsed
- KaamCard: shareable QR profile with a live trust score

## Tech Stack
React + Tailwind PWA, Node.js on AWS Lambda, DynamoDB, S3, ElevenLabs (voice), Amazon Bedrock, Amazon Location Service
